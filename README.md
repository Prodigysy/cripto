## Лабораторная работа № 2

**Тема:** генерация псевдослучайных последовательностей
**Вариант:** 5 (средний уровень)
**Генератор:** Эйхенауэра–Лена с обращением, алфавит `A = {0..19}`, `N = 20`

### Структура

```
lab_2/
├── lab2_var5.py   # генератор, вычисление периода, подбор параметров,
│                  # три статистических теста NIST SP 800-22
├── report.md      # отчёт по лабораторной работе (таблицы результатов)
├── results.txt    # полный вывод запуска python lab2_var5.py
├── data.pi        # контрольная последовательность: 10^6 бит числа π
└── data.e         # контрольная последовательность: 10^6 бит числа e
```

### Задание

1. Реализовать приложение, генерирующее псевдослучайную равномерно распределённую
   последовательность произвольной длины из заданного алфавита.
2. Вычислить период последовательности; подобрать параметры генератора так,
   чтобы период был максимальным.
3. Сгенерировать 10⁶ бит и исследовать их тремя статистическими тестами
   NIST SP 800-22 (по варианту): неперекрывающихся шаблонов, кумулятивных сумм,
   на периодичность. Предварительно проверить тесты на контрольных
   последовательностях π и e (таблица 1 методички).

### Запуск

```bash
python lab2_var5.py
```

Зависимости: **только стандартная библиотека Python 3** (проверено на Python 3.11).

Скрипт одной командой выполняет все пункты:

1. генерирует последовательности произвольной длины из алфавита `{0..19}`;
2. перебирает все 8000 комбинаций параметров `(a, c, x₀)`, находит
   максимальный период `T_max = 6` (оптимальные пары `(a, c)` перечисляются);
3. проверяет три теста на `data.pi` / `data.e` и сверяет P-value с таблицей 1
   методички (все значения совпадают с точностью до 6 знаков);
4. генерирует 10⁶ бит (200 000 символов орбиты × 5 бит) и выводит по каждому
   тесту честный вердикт ПРОЙДЕН / НЕ ПРОЙДЕН при `α = 0.01`.

### Ключевые результаты

| Параметр | Значение |
|---|---|
| Максимальный период (перебор всех параметров) | **6** |
| Выбранные параметры | `a=1, c=2, x₀=1` (орбита `1, 3, 9, 11, 13, 19`) |
| Сверка тестов с таблицей 1 (π, e) | OK — точность до 10⁻⁶ |
| 10⁶ бит генератора, три теста NIST | все три — **НЕ ПРОЙДЕНЫ** |

Провал тестов закономерен и доказан в отчёте: при составном модуле `N = 20 = 2²·5`
обратимы только 8 элементов алфавита, поэтому период генератора Эйхенауэра–Лена
не превышает 6 символов (30 бит битового потока). Реализации тестов корректны —
на истинно случайной последовательности все три проходят (положительный контроль
приведён в `report.md`).

Подробности, формулы, таблицы P-value и обоснование — в [`report.md`](report.md).
