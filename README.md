## Лабораторная работа № 3. Генерация простого числа

> Находится в ветке **`лаб-3`**.

**Вариант:** 2 — **тест Леманна** (вместо Рабина–Миллера).

### Задание

1. Реализовать приложение, генерирующее простое число по схеме методички:
   1. сгенерировать случайное `p`-битовое число `n`;
   2. установить старший и младший биты равными 1 (старший гарантирует
      требуемую длину, младший — нечётность);
   3. убедиться, что `n` не делится на маленькие простые числа
      (проверка делимости на все простые < 2000 — наиболее эффективный вариант);
   4. выполнить **пять тестов Леманна** со случайными `a`; если `n` не проходит
      хотя бы один — сгенерировать другое `n` и повторить.

### Тест Леманна

1. Выбрать случайное `a < n`.
2. Вычислить `t = a^((n-1)/2) mod n`.
3. Если `t ≠ ±1 (mod n)` — `n` составное.
4. Иначе ответ «неизвестно», вероятность ошибки ≤ 1/2.

После `k` повторений вероятность пропустить составное число ≤ `1/2^k`
(при 5 раундах — ≤ 1/32 ≈ 3,1 %).

### Структура (ветка `лаб-3`)

```
lab_3/
├── lab3_var2.py   # генерация кандидата, решето < 2000, тест Леманна
├── report.md      # отчёт: схема теста, таблица результатов, верификация
└── results.txt    # полный вывод команды python lab3_var2.py 256
```

### Запуск

```bash
python lab3_var2.py        # p = 256 бит по умолчанию
python lab3_var2.py 512    # произвольная длина в битах
```

Зависимости: **только стандартная библиотека Python 3**.

### Ключевые результаты (p = 256)

| Параметр | Значение |
|---|---|
| Простых < 2000 для пробных делений | 303 |
| Кандидатов рассмотрено | 65 (55 отбракованы делением, 9 — тестом Леманна) |
| Сгенерированное простое | `94942933123406754198507694485282219814653660938584722167217302014723395203197` |
| Вероятность ошибки | ≤ 1/2⁵ = 0,03125 |

Реализация верифицирована: 10 сгенерированных 64-битных простых и итоговое
256-битное число независимо подтверждены детерминированным тестом
Миллера–Рабина; тест Леманна корректно отбраковывает число Кармайкла 561.

Формулы и полное обоснование — в [`report.md`](report.md).
