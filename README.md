## Лабораторная работа № 2. Генерация псевдослучайных последовательностей

> Находится в ветке **`лаб-2`**.

**Вариант:** 9 (средний уровень)
**Генератор:** LFSR — регистр сдвига с линейной обратной связью над GF(2),
многочлены варианта: `f₁(x) = x⁵ + x² + 1`, `f₂(x) = x⁵ + 1`,
`f₃(x) = x⁵ + x⁴ + x² + 1` (какие примитивны по модулю 2?)
**Статистические тесты NIST SP 800-22 (по варианту):** серий,
неперекрывающихся шаблонов, универсальный Маурера.

### Задание

1. Реализовать приложение, генерирующее псевдослучайную равномерно
   распределённую последовательность произвольной длины из заданного алфавита.
2. Вычислить период последовательности; подобрать параметры генератора так,
   чтобы период был максимальным.
3. Сгенерировать 10⁶ бит и исследовать их тремя статистическими тестами.
   Предварительно проверить тесты на контрольных последовательностях —
   бинарном разложении чисел π (`data.pi`) и e (`data.e`).

### Структура (ветка `лаб-2`)

```
lab_2/
├── lab2_var9.py                 # генератор, период, примитивность, 3 теста NIST
├── test_lab2_var9.py            # юнит-тесты (22 теста, python -m unittest)
├── report.md                     # отчёт: формулы, таблицы, обоснование результатов
├── results.txt                  # полный вывод команды python lab2_var9.py
├── data.pi / data.e              # контрольные последовательности (10⁶ бит π и e)
└── соответствие названий ...txt  # соответствие английских и русских названий тестов
```

### Запуск

```bash
python lab2_var9.py            # все пункты задания одним скриптом
python -m unittest test_lab2_var9.py -v   # юнит-тесты
```

Зависимости: **только стандартная библиотека Python 3** (проверено на Python 3.11).

Скрипт одной командой выполняет все пункты задания:

1. генерирует битовые последовательности произвольной длины (алфавит `{0, 1}`);
2. проверяет примитивность трёх многочленов варианта над GF(2) и перебирает все
   31 ненулевое начальное состояние каждого LFSR, находя максимальный период;
3. проверяет три теста на `data.pi` / `data.e` и сверяет P-value с таблицей 1
   методички (допуск ±0,01);
4. генерирует 10⁶ бит и выводит по каждому тесту вердикт ПРОЙДЕН / НЕ ПРОЙДЕН
   при `α = 0.01`.

### Ключевые результаты

| Параметр | Значение |
|---|---|
| Примитивные многочлены варианта | только `f₁ = x⁵ + x² + 1` |
| Максимальный период `T_max = 2⁵ − 1 = 31` | достигается многочленом `f₁` при любом ненулевом seed |
| Периоды `f₂ = x⁵ + 1`, `f₃ = x⁵ + x⁴ + x² + 1` | 5 (= ord(x⁴+x³+x²+x+1)) и 15 (= ord(x⁴+x+1)) |
| Сверка тестов с таблицей 1 методички (π, e) | OK — все 6 значений в допуске ±0,01 |
| 10⁶ бит генератора, три теста NIST | все три — **НЕ ПРОЙДЕНЫ** |

Провал тестов закономерен и обоснован в отчёте: 5-битный LFSR, даже на
примитивном многочлене, имеет период всего 31 бит — битовый поток повторяется
~32 258 раз на длине 10⁶, и любой статистический тест это немедленно видит
(частотный дисбаланс π = 0,5161, детерминированные счётчики шаблонов
χ² ≈ 2020, сжимаемость fn = 4,95 при ожидаемых 6,20). Реализации тестов
корректны: на контрольных последовательностях π/e все три дают значения
таблицы 1 (положительный контроль), юнит-тесты дополнительно проверяют
примеры из NIST SP 800-22.

Формулы, таблицы P-value и полное обоснование — в [`report.md`](report.md)
ветки `лаб-2`.
