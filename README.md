# Лабораторная работа №1. Простейшие шифры
## Шифр «Решётка Кардано» (Вариант №5)

Программная реализация алгоритма шифрования и дешифрования текста методом блочной перестановки с помощью поворотной решётки Кардано фиксированного размера $8 \times 8$.

---

## 📋 Описание проекта

- **Вариант задания:** №5 (шифрование и дешифрование по решётке Кардано; генератор решётки реализован в соответствии с требованиями варианта №4).
- **Язык разработки:** Python 3 (без сторонних зависимостей).
- **Размер матрицы:** $8 \times 8$ (64 ячейки, 16 отверстий на каждом из 4 положений).

---

## ⚙️ Принцип работы

1. **Формат ключа:**
   - Ключ представляет собой текстовый файл, состоящий из 8 строк по 8 символов (`0` и `1` без пробелов).
   - Символ `1` обозначает вырезанное отверстие, символ `0` — закрытую ячейку.
   - Матрица $8 \times 8$ разбивается на 16 независимых орбит (групп по 4 клетки, переходящих друг в друга при последовательных поворотах на $90^\circ$). При генерации в каждой орбите выбирается ровно одно отверстие, что гарантирует покрытие всех 64 ячеек ровно по одному разу за полный цикл из 4 поворотов ($16 \times 4 = 64$).

2. **Валидация ключа:**
   - Перед шифрованием и дешифрованием программа проверяет корректность файла ключа: размерность $8 \times 8$, допустимые символы и отсутствие взаимных перекрытий отверстий при вращении на $90^\circ$, $180^\circ$ и $270^\circ$.

3. **Шифрование:**
   - Текст обрабатывается блоками по 64 буквы.
   - На каждом из 4 положений решётки открытые ячейки заполняются буквами последовательно (слева направо, сверху вниз).
   - По завершении 4 поворотов зашифрованный блок считывается построчно из полученной таблицы.

4. **Сохранение пробелов и переносов строк:**
   - В соответствии с требованиями методички пробелы и символы конца строки (`\n`) не шифруются и остаются на своих исходных позициях в тексте.

5. **Обработка неполных блоков:**
   - Если последний блок содержит меньше 64 букв, они последовательно занимают доступные ячейки по порядку обхода решётки без добавления лишних символов (паддинга).
   - За счёт этого длина результирующего файла строго совпадает с исходной, а дешифрование остаётся детерминированным.
   - *Особенность реализации:* если в последнем блоке содержится $\le 16$ букв, все они укладываются в первое положение решётки и не перемешиваются между собой.

---

## 🚀 Запуск и использование

Все операции выполняются через единый CLI-скрипт `cardano.py`:

```bash
# 1. Генерация корректной решётки 8x8 (вариант 4)
python cardano.py gen key.txt

# 2. Шифрование файла
python cardano.py encrypt input.txt key.txt out.txt

# 3. Дешифрование файла
python cardano.py decrypt out.txt key.txt plain.txt
```

---

## 🧪 Результаты тестирования

Алгоритм протестирован на связном тексте объёмом более 40 слов, содержащем пробелы и многострочные переносы:
1. Выполнен полный цикл преобразований: `input.txt` $\to$ `out.txt` $\to$ `plain.txt`.
2. Проведено побайтовое сравнение файлов: `plain.txt` полностью идентичен исходному `input.txt`.
